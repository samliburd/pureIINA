pureIINA (iinatools) Settings

Optional custom path to an FFmpeg executable. If supplied, iinatools will strictly prefer this binary over automatic system PATH discovery. Typical paths: /opt/homebrew/bin/ffmpeg (Apple Silicon) or /usr/local/bin/ffmpeg (Intel).

Default encoder for exported clips. Hardware codecs utilize Apple Silicon Media Engines for high-speed export with minimal CPU load.

When enabled, the interactive video crop bounding box and HUD overlay will activate automatically whenever a video loads (default: disabled).

Optional absolute path to an export directory. If supplied, exported clips will be saved here instead of the input video's parent folder. Can also be overridden per-session via the sidebar.
