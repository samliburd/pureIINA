pureIINA (iinatools) Guide

A native video trimming, interactive cropping, and FFmpeg transcoding toolkit integrated directly into IINA.

Quick Workflow:
  1. Seek playback and click Set Start / Set End to establish cut boundaries.
  2. (Optional) Toggle Crop Mode to interactively isolate an area of the video.
  3. Choose a video encoder and click Run FFmpeg to export, or Show Command to copy the terminal command.

1. Trimming & Cutting

iinatools allows millisecond-accurate boundary selection without leaving the video player:

  • Set Start: Captures the player's current playback position as the starting timestamp (HH:MM:SS.mmm).
  • Set End: Captures the player's current playback position as the concluding timestamp.
  • Play / Pause: Controls playback directly from the sidebar.
  • Output Filename: Enter a custom name for the exported video. Defaults to <videoname>.output.mp4.

2. Interactive Spatial Cropping

Crop any video visually with instant on-screen feedback:

  • Crop Mode: ON / OFF: Activates the non-blocking HUD canvas directly over the video player.
  • Crop Format: Defined as Width:Height:X:Y in video pixel space (e.g., 1280:720:0:0).
  • X / Y Offset Sliders: Adjust horizontal and vertical placement in real-time. Sliders are bounded to prevent cropping outside video dimensions.
  • Even-Integer Normalization: All crop dimensions and coordinates are automatically rounded to the nearest even number (divisible by 2). This ensures strict compliance with standard yuv420p chroma subsampling.

3. Automatic HDR-to-SDR Tonemapping

When HDR source media (HDR10 / SMPTE ST 2084 / PQ or HLG / ARIB STD-B67) is detected, iinatools automatically injects a filmic Hable tonemapping filtergraph:

zscale=t=linear:npl=100,format=gbrpf32le,zscale=p=bt709,tonemap=tonemap=hable:desat=0,zscale=t=bt709:m=bt709:r=tv,format=yuv420p

This maps wide color gamuts and high luminance levels down to standard BT.709 SDR with accurate color tags, preventing washed-out or desaturated exports.

4. Video Codecs & Hardware Acceleration

Codec Option Encoder Engine Best For Parameters

x265 Software libx265 High compression efficiency; smaller file sizes with hvc1 tagging. CRF 22, Preset Fast

5. FFmpeg Configuration & Provisioning

iinatools provides multiple methods to resolve an FFmpeg executable:

  • Preferences Path: Enter a custom binary path in IINA Settings → Plugins → iinatools → Preferences. A supplied path always takes top priority.
  • System Discovery (Find ffmpeg): Searches Homebrew (/opt/homebrew/bin, /usr/local/bin), MacPorts, and system $PATH via an interactive login shell.
  • Download ffmpeg: Automatically fetches and extracts the official static macOS binary from Evermeet into isolated plugin storage (@data/bin/ffmpeg).

6. Output Directory Precedence

When saving video clips, destination directories are resolved in the following order:

  1. Sidebar Session Directory: Selected via the Set Output Dir button in the active sidebar.
  2. Preferences Default Directory: Configured in the plugin Preferences tab (supersedes the input folder).
  3. Source Video Folder: If neither is set, clips are saved in the same directory as the input video file.
